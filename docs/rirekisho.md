## 自己PR

業務を深く理解し、「つくる」で終わらせず「動かしきる・成果を出しきる」まで責任を持つエンジニアです。官公庁の法令作成業務、法人向けの販売・出荷・審査といった商流、1on1 支援 SaaS まで、複数の業務領域で要件定義から運用までを一気通貫で担当してきました。対向システムがある開発では、自システムの作り込みより先に疎通とインタフェースの確認を優先する進め方を取り、運用保守ベンダーが 4 ヵ月と見積もった API 開発を 2 ヵ月で完成させています。

直近は KAKEAI 株式会社で開発責任者として最大 25 名規模の開発組織にクロスファンクショナルチームを導入し、リリース遅延を半分ほどに削減しました。あわせて生成 AI を前提に開発プロセスを再設計しています。現在はテックリードとして、中核製品のリニューアルで AI 機能とデータ集計基盤の開発をリードしています。

「1 人が短期的に 1.1 倍の生産性を出すより、100 人が長期的に 1.01 倍の生産性を出せる仕組みをつくる」ことをミッションとし、個人の完遂力を組織の仕組みへ広げることを心がけています。
